# Yes or No Random Generator 🎯

A free online tool that gives you an instant random **Yes or No** answer. Ask a question, press a button, and let chance decide.

🔗 **Live site:** [yesornorandomgenerator.com](https://yesornorandomgenerator.com/)

## Features
- 🃏 **Card mode**: flip a card to reveal YES or NO
- 🎡 **Wheel mode**: spin an 8-slice wheel (4 Yes, 4 No)
- ⚡ **Quick answer**: instant result
- 🔒 Fair 50/50 odds using the browser's secure random number generator
- 📱 Works on mobile, tablet and desktop
- 💸 Free, no signup, no limits

Each answer is generated with `crypto.getRandomValues()`, so every result is independent and has an equal 50% chance.
